# Supply Chain RAG Chatbot

This project is a Retrieval-Augmented Generation (RAG) chatbot designed to answer questions based on supply chain governance policies and performance data.

## Current Files
- `SupplyChain_Governance_Policy_v3.2 1.pdf`: Supply Chain Governance Policy document.
- `supplier_performance_data.csv`: Supplier performance metrics/data.
